# Quizzes

After every couple of chapters, there's a quiz in this directory that tests
your knowledge of several lessons at once.

Quiz 1 works like Rustlings' quizzes: there's nothing to fix. Its file
describes a small view, and you write it from scratch.

The other quizzes don't mark the broken lines with a TODO. Instead, each file
lists the bugs that testers reported. Reproduce each one in the preview, trace
it back to the code, and fix it. The check stops at the first symptom it finds,
so fix them in the order it reports them.

Each quiz has three hints (`h`): a strategy, the lessons each fix reuses, and
finally the exact changes. Try to get as far as you can before you reach for the
last one.
