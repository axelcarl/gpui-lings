# Quizzes

After every couple of chapters there is a quiz in this directory that tests
your knowledge of several lessons at once, as in
[Rustlings](https://github.com/rust-lang/rustlings/tree/main/exercises/quizzes).

Unlike the lessons, a quiz doesn't mark the broken lines with a TODO. Its file
lists the bugs testers reported instead. Reproduce each one in the preview,
trace it back to the code, and fix it. The check stops at the first symptom it
sees, so fix them in the order it reports them.

- [20 · Quiz 1: compact inspector](quiz1.rs): responsive layout, scrolling,
  disabled state and where key events go (lessons 12–19).
- [24 · Quiz 2: command menu](quiz2.rs): actions, focus and keyboard routing
  (lessons 07–23).
- [28 · Quiz 3: searchable results](quiz3.rs): a native text input, background
  work and stale results (lessons 09–27).
- [38 · Quiz 4 (capstone): small native workspace](quiz4.rs): entities, layout,
  actions, async work and persistence from the whole course.

Each quiz has three hints in the session (`h`): a strategy, the lessons each
fix reuses, and finally the exact changes.
