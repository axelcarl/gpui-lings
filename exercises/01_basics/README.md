# Foundations · 01–03

Start with one piece of data, then change it, then derive visible text from it.
The app supplies the GPUI wiring so these first edits stay small.

- [01 · Greeting](../../playground/src/exercises/basics/greeting.rs): build an element tree with `div().child(...)`.
- [02 · Counter](../../playground/src/exercises/basics/counter.rs): change owned state in response to a click.
- [03 · Milestone](../../playground/src/exercises/basics/milestone.rs): derive the interface from a single source of truth.

The task, expected behavior, and checks live in each Rust file. Save to check;
use `h` for a hint and `n` to continue. `g` reads the same source instructions.

Reference: [GPUI introduction](https://github.com/zed-industries/zed/blob/main/crates/gpui/README.md).
