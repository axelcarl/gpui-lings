# Exercise to guide mapping

Rustlings pairs its exercises with chapters of the Rust book. GPUI has no book
yet, so each chapter README here explains its ideas briefly and links to the
[GPUI Kit guides](https://gpui-kit.com/docs/), which cover GPUI one topic at a
time. Exercise hints (`h`) link to the guide section for that exercise.

| Exercise | Guides |
| --- | --- |
| basics | [Getting Started](https://gpui-kit.com/docs/getting-started/), [Render](https://gpui-kit.com/docs/render/) |
| views | [Style](https://gpui-kit.com/docs/style/), [Entity](https://gpui-kit.com/docs/entity/) |
| contexts | [Context](https://gpui-kit.com/docs/context/), [Entity](https://gpui-kit.com/docs/entity/), [Event](https://gpui-kit.com/docs/event/) |
| keyboard | [Focus](https://gpui-kit.com/docs/focus/), [Event](https://gpui-kit.com/docs/event/), [Action](https://gpui-kit.com/docs/action/), [KeyBinding](https://gpui-kit.com/docs/keybinding/) |
| lifetimes | [Entity](https://gpui-kit.com/docs/entity/), [Context](https://gpui-kit.com/docs/context/), [Task](https://gpui-kit.com/docs/task/) |
| layout_states | [Style](https://gpui-kit.com/docs/style/), [Window](https://gpui-kit.com/docs/window/), [Event](https://gpui-kit.com/docs/event/) |
| dispatch | [Focus](https://gpui-kit.com/docs/focus/), [Action](https://gpui-kit.com/docs/action/) |
| async | [Task](https://gpui-kit.com/docs/task/) |
| application | [Window](https://gpui-kit.com/docs/window/), [Global](https://gpui-kit.com/docs/global/), [Multi Window](https://gpui-kit.com/docs/multi-window/) |
| quality | [Accessibility](https://gpui-kit.com/docs/accessibility/), [Testing](https://gpui-kit.com/docs/test/), [RenderOnce](https://gpui-kit.com/docs/render-once/) |

If you'd like one longer read to follow along with, take Zed's
[Ownership and data flow in GPUI](https://zed.dev/blog/gpui-ownership). It
explains entities, contexts, `notify`, `observe` and events, which covers most
of chapters 02–05.
